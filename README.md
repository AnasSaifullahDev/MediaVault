# MediaVault

MediaVault is a personal media tracker built with React and Vite.

## Project Goals

- Track books, manhwa, anime, and TV series.
- Organize titles by category and status.
- Track reading or watching progress.
- Search and filter your personal library.
- View library statistics on a dashboard.

## Tech Stack

- React
- Vite
- JavaScript
- CSS / Tailwind CSS (planned)
- Supabase (planned)

## Development

This project is currently under development as a learning project.

To run it locally:

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```
